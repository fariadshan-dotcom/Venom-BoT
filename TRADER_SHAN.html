LIVE DATA CONNECTION — OHLC API

Backend URL দিলে নিরাপদে ১ মিনিটের OHLC ডেটা পরীক্ষা করা যাবে। API key এই HTML-এ রাখা হয় না।

API এখনো সংযুক্ত নয়। Backend deploy করার পর URL দিন।

সতর্কতা: এই প্যানেল নিজে থেকে কোনো Quotex trade করে না। ডেটা endpoint বা symbol ভুল হলে সিগন্যাল তৈরি হবে না।

১. স্ক্রিনশট দিন

ফোন আড়াআড়ি (ল্যান্ডস্কেপ) করে চার্ট জুম আউট করুন, যাতে কমপক্ষে ৫০-৬০টা ক্যান্ডেল দেখা যায়। ক্যান্ডেল শেষ হতে ২০-২৫ সেকেন্ড বাকি থাকতে স্ক্রিনশট নিন।

২. ক্যান্ডেলের অংশ (নিজে ঠিক হয়)

স্ক্রিনশট দিলেই হলুদ বক্স নিজে ঠিক হয়। ঠিক না লাগলে স্লাইডার দিয়ে বদলান, বক্সে শুধু ক্যান্ডেল থাকবে।
